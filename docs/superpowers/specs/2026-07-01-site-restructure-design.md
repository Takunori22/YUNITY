# YU-NITY サイト再構成 設計書

作成日: 2026-07-01

## 概要

現行サイトは「ホーム／銭湯ガイド／アクセス／アバウト／ブログ」の5タブ構成。
これを **ホーム／銭湯紹介／マナー／アバウト** の4タブに再編し、各ページの中身を刷新する。

- ブログ機能、既存アクセスタブ、既存ギャラリー、既存チーム紹介、課題セクション、
  「三つの橋を架ける」(Solution)セクションを削除
- 銭湯紹介・マナーの2ページを新規に本格コンテンツとして作成
- アバウトはチーム紹介を拡充して作り直す
- ホームはヒーロー／ギャラリー(新規プレースホルダ)／銭湯紹介／マナー／アンケート／アバウト の6セクション構成に再編

対象は単一の `index.html`（タブ切替SPA、`.page`要素をJSで出し分ける既存アーキテクチャ）。この構造は変更しない。

## 情報アーキテクチャ

### ナビゲーション

`nav__links` / `footer__nav-list` / `tabs.js` の `VALID_TABS` を以下に変更:

```
["home", "sento", "manner", "about"]
```

- `home` = ホーム
- `sento` = 銭湯紹介（現 `guide` を置き換え、`page-guide` → `page-sento` にリネーム）
- `manner` = マナー（新規タブ）
- `about` = アバウト（既存を維持しつつ中身を差し替え）

`guide` / `access` / `blog` タブ、`page-access` / `page-blog` は削除。

### ホームページ（`page-home`）

温度(`data-temp`)は「ヒーロー→ギャラリー→銭湯紹介→マナー→アンケート(ピーク)→アバウト(やや下げて着地)」の順で推移させる。

| # | セクション | data-temp目安 | 内容 |
|---|---|---|---|
| 1 | Hero | 0.04 | 既存維持 |
| 2 | ギャラリー(新規) | 0.18 | プレースホルダのグリッドギャラリー(詳細は下記) |
| 3 | 銭湯紹介(ホーム版) | 0.35 | 「銭湯文化とは」(既存conceptの文章をベースに再構成) + 大黒湯(文京区)の簡単な紹介 + Googleマップ埋め込み(プレースホルダ) + 「銭湯紹介ページへ」リンク |
| 4 | マナー(ホーム版) | 0.55 | マナーの要点3〜4個をカード形式でハイライト + 「マナーを詳しく見る」リンク |
| 5 | アンケート | 0.92 | 既存維持(据え置き) |
| 6 | アバウト(ホーム版) | 0.78 | チームの簡単な紹介(ミッション一言 + メンバー写真ロールのミニ版) + 「アバウトページへ」リンク。アンケートの熱量から少し落ち着いた"湯上がりの余韻"として着地 |

### 銭湯紹介ページ（`page-sento`）

対象は **大黒湯（文京区）**。ホームで紹介しきれない魅力を深掘りする。

1. ページヘッダー(ラベル+タイトル)
2. 大黒湯のストーリー(歴史・魅力を紹介する読み物、プレースホルダ文章を新規作成)
3. 特徴紹介ブロック(写真×テキストを交互配置、3〜4項目: 外観／番台／浴室／銭湯絵 など) — 画像はすべてプレースホルダ
4. アクセス情報(現行`access-section`の情報を統合): 名称・住所・営業時間・定休日・入浴料・Googleマップ埋め込み(プレースホルダ)・「Googleマップで開く」ボタン
   - 住所・営業時間などの具体値は現行同様ダミーのままとし、後日ユーザーが実データに差し替えられる形にする(マップURLと同じ扱い)
5. マナーページ／アンケートへの導線CTA

### マナーページ（`page-manner`）

日本の銭湯マナーを本格的に紹介する新規ページ。

1. ページヘッダー
2. 導入文(なぜマナーが大切か)
3. 入浴の流れ ステップガイド(番号付き、6ステップ): 受付 → 脱衣所 → 洗い場 → 湯船 → 上がり湯 → 退出後
4. 個別ルール一覧: タトゥーについて、写真撮影禁止、タオルを湯船に入れない、遊泳・潜水禁止、私語は控えめに、飲酒後の入浴は控えるなど
5. 「よくある誤解 Q&A」— 削除する課題セクションにあった「タトゥー禁止という思い込みで躊躇してしまう」等の論点を、統計訴求ではなく安心材料として再構成して掲載
6. アンケート/銭湯紹介への導線CTA

### アバウトページ（`page-about`）

既存6名(多田圭佑・大戸拓知・神尾光季・森田優晟・菅原諒・桑原遼太)を維持し、内容を拡充。

1. ページヘッダー
2. チームの活動理念・発足経緯のストーリー(ゼミ活動としての経緯を含む読み物)
3. メンバーグリッド: 既存6名、各人に自己紹介文/意気込みの一言を追加(名前・役割は現行踏襲)
4. アンケートへの導線CTA

現行の `problem-section` と `solution-section` はこのページから完全に削除。

## 削除するもの

- `page-blog` / ホームの `blog-preview-section` / ナビ・フッターの`blog`リンク / i18nの`blog`名前空間
- `page-access`(単独タブとしては廃止。内容は銭湯紹介ページへ統合)
- 現行 `gallery-section`(横スクロールピン留め版) と `src/animations/gallery.js`、`tabs.js`内の`initGallery`呼び出し
- `problem-section`、`solution-section`とその関連CSS/JS(カウントアップ、SVGパスアニメーションなど)
- 現行 `team-section` は作り直すが、既存メンバーの氏名・役割データは流用

## 新規ギャラリー(グリッド版)の仕様

ユーザー指定により、横スクロール演出は使わず **CSSグリッドの静的ギャラリー** に変更する。

- レイアウト: レスポンシブなCSS Grid(例: モバイル2列 / タブレット3列 / デスクトップ4列)
- 各タイルはプレースホルダ(画像なし、番号+アイコン+「Coming Soon」的な控えめな表示)。`<img>`を差し込むだけで実画像に置き換えられる構造にする
- アニメーションは既存の`scrollAnimations.js`の`registerAll()`パターンを流用し、`team-card`と同様のフェード+スケール+スタガーで登場させる(専用のピン留めScrollTriggerは不要になるため`gallery.js`は削除)
- reduced-motion時は`reveal.js`の`REVEAL_SELECTORS`に新セレクタを追加して即表示にする

## 技術面の変更点まとめ

- `index.html`: ページ構成を全面的に書き換え(4タブ分の`.page`要素、ホームの6セクション)
- `src/animations/tabs.js`: `VALID_TABS`変更、ギャラリー初期化トリガーの削除(グリッド化に伴い不要)、`page-guide`→`page-sento`のID変更に追随
- `src/animations/gallery.js`: 削除
- `src/animations/scrollAnimations.js`: problem/solution関連の登録・カウントアップ・SVGパス処理を削除。新セクション(銭湯紹介ページ、マナーページ、アバウトページ、新ギャラリー)の要素を`registerAll()`で登録
- `src/utils/reveal.js`: `REVEAL_SELECTORS`をproblem/solution削除・新セクション追加で更新
- `src/styles/*.css`: 新セクション用のクラス(ステップガイド、Q&A、特徴紹介ブロック、グリッドギャラリーなど)を追加。不要になったproblem/solution/gallery(横スクロール)/blog関連CSSを削除
- `src/i18n/{ja,en,zh,ko}.js`: `nav.sento` / `nav.manner`を追加、`blog`/`problem`/`solution`名前空間を削除、`sento.*` / `manner.*` / `about.*`(拡充)の新規キーを4言語すべてに追加。日本語を軸に作成し、英語・中国語(簡体字)・韓国語も全文翻訳する

## 保留事項(ユーザーが後日対応)

- Googleマップ埋め込みURL(ホーム銭湯紹介セクション・銭湯紹介ページ双方)
- 大黒湯の正確な住所・営業時間・定休日・入浴料(現状ダミー値のまま実装し、コメントで差し替え箇所を明示)
- ギャラリー・銭湯紹介ページの実写真素材(プレースホルダのまま)
- アバウトページのメンバー写真(現行のrandomuser.imgプレースホルダのまま)

## テスト計画

- `npm run dev`でローカル起動し、4タブすべてが正しく表示・遷移することを確認
- 4言語切り替え(JA/EN/ZH/KO)ですべての新規セクションのテキストが表示されることを確認
- `prefers-reduced-motion`環境で全セクションが正しく表示される(reveal.jsのフォールバック)ことを確認
- モバイル幅でギャラリーグリッド・ステップガイドなどのレイアウト崩れがないことを確認
- ブラウザ(Playwright)で実際に操作して確認する
